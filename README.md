## Tech Stack

- **HTML5 / CSS3 / JavaScript** — no frameworks, no build step
- **Firebase Hosting** — deployed via `firebase deploy`
- **GitHub Actions** — CI/CD workflow for automatic deploys on push

---

## Running Locally

No install needed — just open the file directly:

```bash
git clone https://github.com/jarquecarl/portfolio.git
cd portfolio

# Open in browser
open index.html
# or just drag index.html into your browser
```

For a local dev server (optional):

```bash
npx serve .
```

---

## Deployment

Hosted on Firebase. To redeploy:

```bash
firebase deploy
```
